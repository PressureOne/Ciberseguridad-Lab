## 🧠 Conceptos Aprendidos

1. **Dirección IP:** Es la dirección lógica de un dispositivo en la red.
   - *IP Privada:* Se usa dentro de la red local (ej. 192.168.1.X).
   - *IP Pública:* Es la dirección con la que navego hacia Internet.
2. **Dirección MAC:** Es la identificación física y única de la tarjeta de red del dispositivo.
3. **Puertos:** Son las "puertas" lógicas de comunicación.
   - **HTTP (Puerto 80):** Tráfico web sin cifrar.
   - **HTTPS (Puerto 443):** Tráfico web cifrado y seguro.
